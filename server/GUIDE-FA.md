# سرور قیمت منو (برای مشتری واقعی)

دموی گیت‌هاب در «حالت نمایشی» کار می‌کند: تغییر قیمت فقط روی همان مرورگر دیده می‌شود.
برای کافه‌ی واقعی که تغییر قیمت باید برای **همه‌ی مشتری‌ها** دیده شود، این سرور کوچک را روی یک هاست ایرانی راه بینداز.
هیچ کتابخانه‌ای لازم ندارد و فقط Node.js نسخه‌ی ۱۸ به بالا می‌خواهد.

## راه‌اندازی روی هاست ایرانی (مثلاً لیارا)
1. یک برنامه‌ی Node.js بساز و محتوای همین پوشه‌ی `server` را آپلود کن.
2. این متغیرها را در تنظیمات برنامه وارد کن:
   - `ADMIN_PASSWORD`: رمز پنل کافه (حداقل ۶ کاراکتر، رمز قوی بگذار)
   - `ALLOWED_ORIGIN`: آدرس منوی کافه، مثلاً `https://cafe-x.ir`
   - `DATA_DIR`: پوشه‌ای که یک **دیسک دائمی** رویش وصل شده (مثلاً `/app/data`). اگر دیسک دائمی وصل نباشد، با هر بار ری‌استارت قیمت‌ها پاک می‌شوند.
3. دستور اجرا `npm start` است. پورت از متغیر `PORT` خوانده می‌شود.
4. آدرس `https://آدرس-سرور/api/health` را باز کن. باید `{"ok":true}` ببینی.

## وصل کردن منو به سرور
موقع ساخت منو، آدرس سرور را بده:
```
VITE_MENU_API=https://آدرس-سرور npm run build
```
یا در `src/config.js` مقدار `MENU_API` را بنویس. حالا پنل در `آدرس-منو/#/admin` با رمز سرور کار می‌کند و هر تغییر همان لحظه به همه‌ی گوشی‌ها می‌رسد.

## چیزهایی که پنل انجام می‌دهد
- تغییر قیمت هر آیتم (و هر دو قیمت آیتم‌های دو دانه‌ای)
- «موجود / تمام شد»
- افزایش یا کاهش گروهی قیمت‌ها با درصد (گرد شده به ۵ هزار تومان)
- بازگشت به قیمت‌های اولیه

قیمت‌ها در فایل `DATA_DIR/overrides.json` ذخیره می‌شوند. برای پشتیبان‌گیری همین یک فایل کافی است.
